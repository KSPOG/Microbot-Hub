# Auto Repair Agent

Autonomously observes KSP plugins, diagnoses failures and sends validated source fixes back through KSP Source Loader

| | |
|---|---|
| Version | 0.1.0 |
| Works with Microbot | 2.6.19 or newer |
| Author | Unknown Author |
| Tags | ksp, agent, repair, debug, autonomous, development |

## How to install

1. Open the Microbot client and click the Microbot button.
2. Open the Plugin Hub and search for **Auto Repair Agent**.
3. Click install. The plugin then appears under Installed, where you can turn it on and open its settings.

This plugin has no written guide yet. If you use it and want to help other players, open a pull request on the [Microbot Hub repository](https://github.com/chsami/Microbot-Hub) that adds a `docs/README.md` for it.
